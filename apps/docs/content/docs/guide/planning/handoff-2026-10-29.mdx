- **Never commit an Iconem share link** (`api.iconem.com/s/…`). They are bearer credentials. The
  Angkor and iconem-open mosaics exist only as machine-local manifests in `.local/aggregate-sets/`.
- Angkor and Geghard repos are private; do not worry about them in open-data work.
- Commits end with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
- On Windows, start Node servers with PowerShell `Start-Process`, not from the Bash tool (sandboxed
  servers die); they take ~10 s to come up (canvas/GLib load). Screenshots via headless Chrome/CDP.
- Memory for this project lives in `~/.claude/projects/C--Dev-Iconem-3d-tiles-converters/memory/`.
