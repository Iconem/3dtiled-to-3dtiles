title: 3dtiled-to-3dtiles
description: Offline Converter Packages (CLI/js SDK) and a live streaming middleware from tiled point-cloud/mesh/Gaussian-splat formats to OGC 3D Tiles
---

Converters (offline CLI/SDK) and a live streaming middleware (`packages/tile-server`) that turn tiled
point-cloud, mesh, and Gaussian-splat formats — COPC, Potree, I3S, streamed-SOG, LCC, RAD, Bentley 3MX,
MapTiler GeoSplats — into standard [OGC 3D Tiles](https://www.ogc.org/standard/3dtiles/), consumable by
any 3D-Tiles-compatible viewer with no pre-conversion step.
