3D Tiled local middleware

starting the tile-server…

Point this at a tiled dataset — on this machine or a public URL — and it serves a live OGC 3D Tiles endpoint. Nothing is uploaded: the conversion happens here, on demand. Paste the resulting URL into Cesium for Unreal/Unity, QGIS, or CesiumJS.

Place a local dataset on the globe (for sources with no georeference)

Applied as a root ENU transform in the tileset itself, so every client gets it — not just this preview. Sources that carry their own georeference ignore these.

Writes the dataset above into a folder that any web server, S3 bucket or Cesium for Unreal can host without this app. The equivalent CLI command is shown below.

tile-server (default): already running with every adapter loaded, reports structured progress, keeps going while you switch tabs, and serves the result back for the preview buttons. CLI subprocess: the exact command below in its own process — a crash or memory blow-up cannot take the tile-server down; same code, progress parsed from its output. With the offline converter it does not need the server at all (a crawl still reads the tileset URL the server serves). Prefer it for very large conversions. Needs the desktop app — not available in a plain browser.
